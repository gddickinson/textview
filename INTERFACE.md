# INTERFACE.md — TextView project navigation map

> **Tests live in `tests/`** — run `python3 -m pytest` (full, ~1s) or
> `python3 -m pytest -m "not slow"` (skips subprocess tests). See
> `tests/README.md` for what's covered.

A modular PyQt6 GUI for displaying text, code, markup, and document files
with live-updating display configuration and many export formats.

## Top-level

| File | Purpose |
| --- | --- |
| `main.py` | Entry point. Creates `QApplication`, opens `MainWindow`, optionally loads a file given as argv. |
| `requirements.txt` | Pinned third-party dependencies. |
| `INTERFACE.md` | This file — navigation map. |
| `SESSION_LOG.md` | Running log of project progress. |
| `CLAUDE.md` | Per-project Claude instructions (references `@INTERFACE.md`). |
| `sample_files/` | A few example inputs (markdown, code, json) for trying out the viewer. |

## `src/` package

| File | Contains |
| --- | --- |
| `__init__.py` | Package docstring listing public modules. |
| `settings.py` | `DisplaySettings` (dataclass of every live-tunable display option) and `SettingsManager` (persists via `QSettings`, emits `changed` signal on update). |
| `themes.py` | `THEMES` dict of named color palettes (Light, Dark, Solarized Dark/Light, Monokai, Dracula, Nord, Sepia, High Contrast, GitHub) plus helpers `get_theme()` / `theme_names()`. |
| `file_loader.py` | `detect_format(path)`, `load_file(path)` (handles encodings + dispatches to document extractors), `file_info(path)`, `is_document(path)`, the extension → format map, and the supported-extensions list used in dialogs / drag-and-drop. |
| `document_extract.py` | `extract_pdf`, `extract_docx`, `extract_docx_html` (mammoth, preserves headings/lists/tables/inline images), `extract_rtf`, `extract_epub`, `extract_odt`. Plain-text extractors return strings; errors raise `DocumentExtractionError`. |
| `rich_doc_controller.py` | `RichDocController` — caches a themed HTML rendering for formats that have a rich representation (currently DOCX). The MainWindow loads it on file open and the viewer flips between rendered/text via Ctrl+T. |
| `latex_controller.py` | `LatexController(QObject)` — compiles `.tex` source to PDF asynchronously via `QProcess`. Engine search order: `latexmk` → `pdflatex` → `xelatex` → `lualatex` (configurable via `preferred_engine`). Auto-upgrades to xelatex when the source uses `fontspec` / `\setmainfont` / unicode-math. Compiles in a temp build directory and copies sibling assets (`.bib` / `.cls` / `.sty` / images, capped by count + size) so the document can resolve `\input` / `\includegraphics`. Emits `finished(ok, pdf_path, message)` and a raw `output(text)` stream. `pick_engine(preferred)`, `available_engines()`, `needs_unicode_engine(source)` are module-level helpers. |
| `templates.py` | File-creation template registry. `Template(id, name, format, extension, body, category, description)` dataclass + `list_templates()` / `by_id(id)` / `categories()` helpers. ~25 entries spanning **Prose / docs** (README, CHANGELOG, LaTeX article, HTML5), **Data** (JSON, YAML, TOML, CSV, JSONL), **Code** (Python script, pytest module, JS / TS / Bash / Rust / Go), **DevOps** (Dockerfile, .gitignore, GitHub Actions, .editorconfig), **Notebooks** (empty .ipynb). Pure data — no I/O — so the same registry can drive future LLM `create_from_template` tools. |
| `templates_dialog.py` | `show_new_from_template(window)` — modal launcher (Ctrl+Alt+N). Two-pane splitter: categorised list of templates on the left, live preview on the right. **Create as untitled** loads the body into an unsaved buffer and drops the editor into edit mode (`_open_as_untitled`). **Save to file…** prompts for a destination, writes the body, then runs the file back through `MainWindow.open_file` so detection / view-mode / syntax highlighting all reflect the new format from the first paint. |
| `save_as.py` | Format-aware Save As registry + dispatcher. `Conversion(id, from_format, to_extension, to_format, description, convert, requires)` dataclass — `convert` returns `str` (text out) or `bytes` (binary out, e.g. `.xlsx`). Built-in converters: **markdown ↔ html** (`markdown` lib, `markdownify` fallback to plain-tag-strip), **JSON ↔ YAML ↔ TOML** cross-conversion (deps: pyyaml / tomli_w / stdlib `tomllib`), **CSV → JSON / JSONL / XLSX / Markdown / HTML**, **JSON (array of objects) → CSV**, **RTF → plain**. Missing third-party deps cause a converter to be silently filtered from `available_conversions()` rather than raising. `show_save_as_with_conversion(window)` is the entry point used by `EditController.save_as`: prompts for a destination, finds a converter for the source-format / target-extension pair, asks Yes/No/Cancel, writes either converted output or the raw buffer, then re-opens the file so view mode flips. |
| `spreadsheet_loader.py` | Excel + OpenDocument workbook reader. `list_sheets(path)` returns sheet names in workbook order; `load_sheet_as_csv(path, sheet)` extracts one sheet to CSV-shaped text so the existing `TableView` does the rendering (integers stay integers via `_format_cell`). XLSX via `openpyxl` (in requirements), `.ods` via lazy `pandas` + `odfpy`, legacy `.xls` via lazy `xlrd`. Missing optional readers raise `SpreadsheetReadError` with an install hint. `show_sheet_picker(window)` is the **Table → Switch sheet…** action handler — modal `QInputDialog` lists sheets, loading swaps content into the active table view without reopening the file. |
| `sqlite_loader.py` | Read-only SQLite browser. `list_tables(path)` returns tables + views (skips `sqlite_*` bookkeeping). `load_table_as_csv(path, table, row_cap=100_000)` extracts one table to CSV text (with a trailing `# (truncated…)` line when the cap fires); `run_query_as_csv(path, sql)` runs ad-hoc SELECTs against the same read-only connection so writes are blocked by SQLite itself. Connection opened via `file:…?mode=ro` URI so the user's database is never mutated. `looks_like_sqlite(path)` is a magic-byte sniff used by `file_loader` to safely fall back to plain-text for `.db` files that aren't actually SQLite (Berkeley DB, LevelDB, …). `show_table_picker(window)` = **Table → Switch table…**; `show_query_runner(window)` = **Table → Run SQL…** (Ctrl+Shift+Q). |
| `archive_loader.py` | List + extract members of ZIP / TAR / TAR.GZ / TAR.BZ2 / TAR.XZ / 7z archives. `Member` dataclass (name, size, compressed_size, mtime, is_dir). `list_members(path)`, `render_listing_markdown(path)` (header + summary + sortable markdown table; member names with `|` are escaped), `extract_member(path, name, dest_dir)`, `extract_all(path, dest_dir)`. `_safe_join` refuses absolute paths and `..` components so a malicious archive can't write outside the destination. ZIP / TAR via stdlib; `.7z` lazy-imports `py7zr` with a friendly error. `show_extract_member_picker(window)` and `show_extract_all(window)` are the **Run → Archive: extract member… / extract all…** action handlers. |
| `renderers.py` | `apply_pygments(viewer, content, path, style)` for syntax highlighting; `render_markdown_html(content, theme)` for markdown→HTML; `escape_to_html(text)` helper. |
| `pdf_renderer.py` | `PdfController` — owns a `QPdfDocument`, attaches it to a `QPdfView`, applies page-mode/zoom settings, and rasterizes pages directly to `QImage` for headless screenshots. |
| `image_view.py` | `ImageView` — `QScrollArea`+`QLabel` viewer for image files. Static / multi-frame images via `Pillow` (PNG/JPG/BMP/WEBP/TIFF/HEIC/JP2/ICO/TGA — including multi-page TIFF and multi-frame WebP), with `QImageReader` as a fallback for SVG. Animated GIFs via `QMovie`. Zoom (Ctrl+wheel, Ctrl+/Ctrl-), fit-to-window (Ctrl+0), actual size, rotate, theme-tinted background, multi-frame nav (`set_frame` / `step_frame`), live brightness / contrast / saturation / gamma adjustments. **Eyedropper** (`set_pick_mode`) → `color_picked(r, g, b, x, y)`. **Crop** (`set_crop_mode`) → `QRubberBand` selection → `crop_selected(QRect)`; `crop_to_pixmap(rect)` maps the label-coord rect into the full-resolution pre-zoom pixmap. Emits `loaded(n_frames, has_adj)` and `frame_changed(idx)`. |
| `image_adjust.py` | `adjust(pil_img, brightness=1, contrast=1, saturation=1, gamma=1)` (PIL `ImageEnhance` + power-law gamma LUT) and `pil_to_qimage(img)`. Pure functions — no Qt widget coupling. |
| `image_panel.py` | `ImagePanel(QDockWidget)` — sliders for brightness / contrast / saturation / gamma, Reset button, multi-frame navigator, **Pick / Crop** group (Eyedropper toggle → swatch + RGB hex (auto-copies to clipboard) on color_picked; Crop toggle drives a rubberband on the image; Save crop… opens a file dialog and writes the cropped pixmap). Listens on `ImageView.loaded` / `frame_changed` / `color_picked` / `crop_selected`. Toggle via **Ctrl+Shift+M**. |
| `video_view.py` | `VideoView` — `QVideoWidget` + `QMediaPlayer` + `QAudioOutput` plus a transport bar (play/pause, stop, time slider with current/total time labels, mute, volume). `load(path)`, `play/pause/toggle/stop`, `set_position(ms)`, `teardown()` to release the decoder before a tab close. Codec coverage depends on what the host's Qt build supports (Qt 6.5+ ships FFmpeg by default). Lives in the viewer stack as `MODE_VIDEO`. |
| `metadata.py` | `get_metadata(path, fmt)` — ordered dict of section → key → value. File section (size, mtime, ctime); plus format-specific extractors for images (Pillow EXIF: camera, exposure, GPS), PDF (pypdf metadata + page count + page size), DOCX (python-docx core_properties + paragraph/section/table counts), EPUB (ebooklib DC fields). All extractors are best-effort and never raise into callers. |
| `metadata_panel.py` | `MetadataPanel(QDockWidget)` — left-side dock that renders the metadata sections as grouped form rows; updated on each `open_file`. Toggleable with **Ctrl+I**. |
| `web_view.py` | `WebView` — `QWebEngineView` plus a slim address bar (back / forward / reload / stop, URL line edit with smart load, status pill). Cookies and cache isolated to `~/.cache/TextView/webengine`. Exposes `find_text` for the search bar to retarget. |
| `web_controller.py` | `WebController` — connects the WebView's title/url signals to MainWindow's status bar, owns `open_dialog()` (Ctrl+L) and `load(url)` so the main app stays slim. |
| `runner.py` | `Runner` — async `QProcess` wrapper. `run_argv` / `run_shell` / `run_file` / `run_python_snippet` / `stop`. Configurable `LANGUAGES` map (Python, Node, TS, Ruby, Go, Bash, Lua, R, PowerShell, Swift, Scala, Clojure, Elixir, Rust, **data validators**: JSON via `python3 -m json.tool`, TOML via `tomllib` → JSON, XML via `xml.dom.minidom.toprettyxml` — all stdlib-only, no install required). Emits `output(text, stream)`, `started(cmd)`, `finished(code, status)`, `error(msg)`. |
| `ansi_format.py` | Stateful ANSI SGR parser → `QTextCharFormat`. Handles 16 colors, bold/dim/italic/underline/strike, RGB extensions. Survives escapes split across reads. |
| `runner_panel.py` | `RunnerPanel(QDockWidget)` — bottom dock with toolbar (Stop, Clear, idle/last-exit indicator), ANSI-formatted output area, shell input bar. |
| `run_controller.py` | `RunController` — owns the panel, exposes `run_current()` (F5), `run_selection()` (Ctrl+Enter), `stop()` (Ctrl+.). HTML / markdown "run" routes to the embedded browser; other formats are blocked with a status-bar message. First-run confirmation prompt with per-file trust persistence. |
| `web_security.py` | `WebSecurityHandler` — connects the WebEngine profile/page to download dialogs, feature-permission prompts, certificate-error confirmations. `apply_profile_settings(d)` translates DisplaySettings into `QWebEngineSettings.WebAttribute` flags. Per-path trust helpers for `web/local_remote_trusted`. |

| `format_db_dialog.py` | `FormatDBDialog(QDialog)` — modal browser with category filter, search box, list pane, and Markdown-rendered detail pane (`QTextBrowser`). `show_format_db(window, ext='')` is the launcher used by Help → File formats database… (Ctrl+Shift+D). |

## Data flow

1. **Load**: user opens a file (menu, drag-drop, or argv) → `file_loader.load_file()` → if it's a document (PDF/DOCX/RTF/EPUB/ODT) it routes through `document_extract` and returns plain text plus a format tag like `"pdf"` or `"docx"`.
2. **Display**: `MainWindow._refresh_view()` looks at the current format and the live settings:
   - PDF with `pdf_render_mode = rendered` → attach `QPdfDocument` to the `QPdfView` (page layout, fonts, images preserved).
   - PDF with `pdf_render_mode = text`, or any document with text-only fallback → set extracted plain text in `CodeViewer`.
   - Markdown / HTML with rendering on → render to HTML, show `QTextBrowser`.
   - Code / data formats → set plain text in `CodeViewer`, then call `apply_pygments()` for token coloring.
3. **Live config**: `ConfigPanel` writes to `SettingsManager`, which emits `changed`; `MainWindow._apply_settings()` re-applies typography, palette, layout, and re-renders.
4. **Export**: menu actions call functions in `exporter.py`, which target either the underlying text or the active viewer widget (for PDF/PNG snapshots). PDF-mode files exported as PDF copy the source bytes through directly.

## Supported export formats — **at save time**

Beyond the export menu (HTML / PDF / MD / TXT / RTF / PNG / Print / Copy), **Save As** now offers format conversion when the chosen extension differs from the current format. Built-in conversions (via `save_as.py`):

- **Markdown ↔ HTML** (both directions)
- **JSON ↔ YAML** *(requires `pyyaml`)*
- **JSON ↔ TOML** *(write requires `tomli_w`; read uses stdlib `tomllib`)*
- **YAML ↔ TOML** *(requires `pyyaml` and `tomli_w`)*
- **CSV → JSON / JSONL / XLSX / Markdown table / HTML table** *(XLSX requires `openpyxl`)*
- **JSON (array of objects) → CSV**
- **RTF → plain text**

Missing optional dependencies make a converter silently unavailable rather than raising — the **Save As** dialog only offers conversions that actually work on the host.
