# Sample Markdown

This file demonstrates the **markdown rendering** in TextView.

## Features

- Headings, lists, **bold**, *italic*, `inline code`
- Tables, blockquotes, fenced code blocks
- Auto-detected formatting on open

> Toggle rendering with `Ctrl+T` to see the raw markdown source.

```python
def greet(name: str) -> str:
    return f"hello, {name}"

print(greet("world"))
```

| Format | Extension | Notes |
| ------ | --------- | ----- |
| Markdown | `.md` | Rendered to HTML |
| PDF | `.pdf` | Text extracted |
| DOCX | `.docx` | Headings preserved |
